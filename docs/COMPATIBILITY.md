# Hardware Compatibility Matrix

## Supported Processors
- **AMD Ryzen**:
  - Ryzen 5000 Series (Cezanne, Lucienne, Barcelo)
  - Ryzen 6000 Series (Rembrandt)
  - Ryzen 7000 Series (Phoenix, Mendocino, Raphael)
  - Ryzen 8000 Series (Hawk Point)
  - Ryzen AI 300 Series (Strix Point)
- **Intel**:
  - 10th Gen to 15th Gen Core / Core Ultra (Arrow Lake, Lunar Lake, Meteor Lake, Raptor Lake, Alder Lake)

## Supported Wi-Fi Controllers
| Vendor | Chipset / Model | Previous Status | With Galaxy Connect Enabler |
|---|---|---|---|
| **MediaTek** | MT7921 (Wi-Fi 6) | Blocked by Continuity | **Fully Supported** |
| **MediaTek** | MT7922 (Wi-Fi 6E) | Blocked by Continuity | **Fully Supported** |
| **AMD / MediaTek** | RZ608, RZ616 | Blocked by Continuity | **Fully Supported** |
| **Realtek** | RTL8852AE / RTL8852BE / RTL8852CE | Blocked by Continuity | **Fully Supported** |
| **Realtek** | RTL8821CE / RTL8822CE | Blocked by Continuity | **Fully Supported** |
| **Qualcomm** | FastConnect 6800 / 6900 / 7800 | Intermittent | **Fully Supported** |
| **Intel** | AX200, AX201, AX210, AX211, BE200 | Supported | **Fully Supported** |

## Supported Samsung Features
- **Samsung Multi Control**: Mouse, keyboard, and clipboard sharing between PC and Galaxy Tab / Phone.
- **Galaxy Connect (Nearby Devices)**: Device discovery bubble, status monitoring, battery levels.
- **Storage Share**: Direct File Explorer integration with Galaxy mobile devices.
- **Second Screen**: Wireless display extension to Galaxy Tab.
- **Quick Share**: High-speed P2P file transfers.
- **Samsung Notes**: Full cloud synchronization with Samsung Cloud.
- **Buds Auto Switch**: Automatic audio handover between Galaxy devices.
